# To-Do List Application

A comprehensive full-stack application to help users manage their tasks effectively, with advanced sorting and filtering capabilities.

## Features

- **User Authentication**: Secure user login and signup functionality.
- **Task Management**:
  - **Add Tasks**: Create new tasks with detailed specifications.
  - **Task Description**: Add comprehensive descriptions for each task.
  - **Urgency/Priority Levels**: Categorize tasks into:
    - `Urgent`
    - `Normal`
    - `Do when time allows`
  - **Task Status Tracking**: Monitor the progress of tasks:
    - `Done`
    - `In progress`
    - `Not started yet`
    - `Missed deadline`
  - **Deadlines**: Set specific due dates and deadlines for tasks.
  - **Remove Tasks**: Delete tasks that are no longer needed.
- **Organization & Search**:
  - **Sort Functionality**: Sort tasks across different parameters to keep your list organized:
    - By *Priority*
    - By *Status*
    - By *Deadline*
  - **Filter Functionality**: Quickly find specific tasks by filtering against:
    - *Priority*
    - *Status*
    - *Deadline*

## Project Structure

The repository is structured into two main components:
- `todolist-frontend`: The frontend web application.
- `todolist-backend`: The backend server handling APIs and database operations.
